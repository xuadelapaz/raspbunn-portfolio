# Artist Commission Website — Normal Profile Version

This version uses a simple, non-editable artist profile.

Features:
- Clean top header with no extra top buttons
- Static artist profile
- Functional commission tabs
- Functional commission request modal
- Functional bookmark buttons
- Functional Work Queue, Followers, Following and About buttons
- Shop and Collection actions
- Responsive layout
- Separate HTML, CSS and JavaScript files
- No profile editor or localStorage profile editing

Run:
1. Extract the ZIP.
2. Keep index.html, style.css and script.js in the same folder.
3. Open index.html in a browser.

No framework or server is required.
